# My home-lab

## Edge setup

| Component                  | Purpose                                                                                     |
|:---------------------------|:--------------------------------------------------------------------------------------------|
| Raspberry Pi Zero 2 W      | Main controller                                                                             |
| Sony IMX500 AI Camera      | On-sensor object detection                                                                  |
| SD Card (64 GB)            | To load Raspberry Pi OS                                                                     |
| Power Bank (10,000 mAh)    | Enables true portability                                                                    |
| PS Vita                    | Good OLED display and to run the game client                                                |
| Wii Remote                 | Connected to PS Vita wirelessly so that the main setup remains untouched                    |
| DIY Cardboard Enclosure    | To keep the whole setup stable, with cable holes to make sure all devices are always charged|

## Development Setup
| Component                              | Purpose                                                                                            |
|:---------------------------------------|:---------------------------------------------------------------------------------------------------|
| My Computer (GTX 1060 + i5 4th gen CPU)| To fine-tune the models and to make and experiment with the algorithm                              |
| My Laptop with stylus                  | To label the images in the dataset                                                                 |
