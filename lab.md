# My home-lab

## Edge setup

- Raspberry Pi Zero 2 W - 
- Sony IMX 500 (Raspberry Pi AI Camera)

| Component                  | Purpose                                                                                            |
|:---------------------------|:---------------------------------------------------------------------------------------------------|
| Raspberry Pi Zero 2 W      | Main controller                                                                                    |
| Sony IMX500 AI Camera      | On-sensor object detection                                                                         |
| SD Card                    | To load Raspberry Pi OS (64 GB)                                                                    |
| Power Bank (10,000 mAh)    | To power the RPi everywhere                                                                        |
| PS Vita                    | Good OLED display and to run the game                                                              |
| Wii Remote                 | Connected to PS Vita wirelessly so that the main setup remains untouched                           |
| Old boxes                  | To keep the whole setup stable, with cable holes to make sure all devices are always charges       |
| My Computer                | To fine tune the models and to make the algorithm                                                  |
